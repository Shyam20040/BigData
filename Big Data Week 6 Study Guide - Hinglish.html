1Machine Learning Basics

DefinitionMachine learning computer systems ka aisa study hai jo bina explicitly programmed hue data se learn karte hain. Models many examples analyse karke task seekhte hain (e.g. bahut si cat images se cats recognise karna, step-by-step rules se nahi). Data ki amount aur quality model ki learning ko strongly affect karti hai. ML hidden patterns aur trends discover karke data-driven decisions possible banata hai.

ML interdisciplinary hai: maths/statistics, computer science/AI, aur domain knowledge (application, data aur outcomes ka use samajhna) – success ke liye zaroori.

Credit-card fraud detection – purchase history se compare hoti hai; bahut different purchase (big-ticket item, foreign location) flag hoti hai.
Handwritten digit recognition – ATMs cheque amounts read karte hain; handwriting kaafi vary karti hai.
Recommendations – "customers who bought this also bought…".
Others – targeted mobile ads, sentiment analysis, climate monitoring, crime-pattern detection, drug-effectiveness analysis.

Related terms

  • Data mining – databases/warehouses mein patterns dhoondhna; ML jaise algorithms ke saath data-access aspects bhi.
  • Predictive analytics – future outcomes predict karne ke liye data analyse karna (sales forecasting, customer behavior).
  • Data science – data (aksar big data) se meaning nikalna, including collection, storage, management; ML techniques use karta hai.

Categories of techniques

TechniqueTypeGoal & examples
ClassificationSupervised, predictiveCategory predict karna: weather, tumor benign/malignant, kal rain, loan risk high/medium/low, tweet sentiment.
RegressionSupervised, predictiveNumeric value predict karna: stock price (rise/fall poochhna classification hai), product demand, test score, rainfall, drug effectiveness.
Cluster analysisUnsupervised, descriptiveSimilar items group karna: customer segments (seniors/adults/teens), topography, tissue, weather patterns, crime hot spots.
Association analysisUnsupervised, descriptiveSaath occur hone wale items/events ke rules; market-basket analysis (milk transactions: 71% bread, 43% eggs, 29% toilet paper), CDs → money-market accounts cross-selling, saath accessed pages.

Supervised = target provided (labeled data); unsupervised = target unknown (unlabeled data).

2The Machine Learning Process

Five steps clear purpose ke saath hote hain (e.g. purchasing behavior study karke sales revenue badhana), aur iterative hain – findings previous step par wapas bhej sakti hain (e.g. Prepare mein quality issue mile → Acquire par return).

  • Acquire: sources (files, databases, internet, mobile) dhoondho, data collect/integrate karo; format conversion aur time/spatial resolution align karni pad sakti hai. Storage se pehle gather, filter, clean karna data acquisition hai – big-data challenge.
  • Explore: correlations, trends, outliers dhoondho. Statistics: mean, median (location), mode, range, standard deviation (spread); negative ya >100 age suspicious. Visualize: histogram (distribution/skew), line (trends), heat map (hot spots), scatter (correlation).
  • Pre-process: clean (missing, duplicate, invalid/inconsistent e.g. six-digit zip, noise, outliers); feature selection (irrelevant/redundant remove, e.g. sales tax vs price; combine/create); transformation (scaling, filtering/aggregation, dimensionality reduction).
  • Analyze: problem type identify, technique choose, model build, new samples par apply aur evaluate.
  • Report: main results, insights, added value communicate; negative results bhi useful; visualizations ke saath backup tables.
  • Act: action decide/implement, user effect consider, impact assess – isse naya cycle start ho sakta hai.

3Generalization & Overfitting

Error rate (misclassification rate) = incorrect predictions ÷ total samples. Model training data par build aur separate test data par evaluate hota hai (training ke waqt unseen). Training error = training par error; test error = test par error = generalization error (new data par performance).

ConditionTraining errorTest errorCause
UnderfittingHighHighData structure learn nahi hui
Good fitLowLowUnderlying trend seekhta hai
OverfittingVery lowHighNoise bhi model karta hai; model too complex (samples ke mukable too many parameters)

Overfit models generalize nahi karte; mapping sahi solve karte hue model ko jitna ho sake simple rakho.

Overfitting in decision trees

Decision tree baar-baar data split karta hai (Outlook → Sunny/Overcast/Rain → Humidity, Wind → Yes/No). Unchecked chhoda toh training data perfectly classify karne tak grow hota hai aur noise ke basis par space partition karta hai. Nodes limit karke complexity control karo:

MethodHow
Pre-pruningRestrictive condition se growth jaldi rokna (e.g. node mein too few samples; impurity improvement threshold se neeche). Premature stop ho sakta hai.
Post-pruningFull tree grow karke bottom-up prune; generalization error improve/unchanged ho toh subtree ko leaf se replace. Aksar better (full tree use), par computationally expensive.

4Validation & Model Selection

Validation set training data ka portion hai jo batata hai training kab stop karni hai. Error vs model complexity (e.g. node count) plot karo: training error girta rehta hai; validation error pehle ghatta, phir badhta hai – rise overfitting dikhata hai. Isliye validation error minimum ho tab stop. Different complexity models mein choose karna model selection hai (kisi bhi model type ke liye); validation error generalization bhi estimate karta hai.

MethodDescription & notes
HoldoutTraining data ka hissa validation ke liye reserve. Limit: training data kam; distributions differ hon toh misleading.
Repeated holdout (random subsampling)Har baar different random holdout se repeat; validation errors ka average.
K-fold cross-validationData ko k disjoint parts mein baanto; har iteration mein ek part validate, total k times; har part ek baar; average error lo aur smallest average model chuno. Common hai, single split variability ghataata hai.
Leave-one-out (LOOCV)K-fold jahan k = N; validation mein ek sample, baaki N−1 par train.
Three datasetsTraining – model parameters fit; Validation – stop kab karna (overfitting avoid); Test – new data par final evaluation. Test set ko model build/tune (cross-validation bhi) ke liye kabhi use nahi karna; end tak untouched rakho. Sab sets mein same class distribution (e.g. 70%/30%) ho, warna results misleading.

5Evaluation Metrics

Yes/no class ke liye (e.g. "is this animal a mammal?"):

True labelPredicted: YesPredicted: No
YesTrue Positive (TP)False Negative (FN)
NoFalse Positive (FP)True Negative (TN)
MetricFormulaMeaning
Accuracy(TP+TN) / (TP+TN+FP+FN)Correct predictions ÷ total
Error rate1 − AccuracyIncorrect ÷ total
PrecisionTP / (TP+FP)Predicted Yes mein se kitne actual Yes – exactness
RecallTP / (TP+FN)Actual Yes mein se kitne find hue – completeness
F-measureF1 = 2·P·R / (P+R)Precision/recall combine; F1 equally weighted, F2 recall ko aur F0.5 precision ko zyada weight deta hai

Example (TP=3, FN=2, FP=1, TN=4): accuracy = 7/10 = 0.7, error rate = 1 − 0.7 = 0.3; precision = 3/4 = 0.75, recall = 3/5 = 0.6.

7Cluster Analysis

Goal: similar items ko groups (clusters) mein organize karna, taaki har group ko closely analyse kar sakein. Objective: intra-cluster differences minimize, inter-cluster differences maximize (same cluster ke samples paas, alag clusters door), similarity measure ke basis par. Applications: purchase history se customer segmentation (sci-fi/non-fiction/children's books), weather patterns, news topics, crime hot spots.

Similarity measureDescription
Euclidean distancePoints A aur B ke beech straight-line distance.
Manhattan distanceSirf axes ke along path (horizontal + vertical steps).
Cosine similarityVectors ke angle ka cosine: cos θ = xi·xq / (‖xi‖‖xq‖); inner product = Σ xi[j]·xq[j]. θ=0 → 1; θ=90° → 0; range −1 to 1 (positive features jaise tf-idf ke liye 0–1). Distance = 1 − similarity. Proper distance metric nahi, sparse vectors ke liye efficient. Normalize = vector norm se divide (e.g. √(1+25+9+1) = 6).

Distance measures ko normalized inputs chahiye ho sakte hain, taaki koi variable disproportionate dominate na kare.

Key pointsClustering unsupervised hai (target nahi); single correct clustering nahi (use-case par depend); clusters labels ke bina aate hain – interpretation/analysis zaroori.

Uses of cluster results

  • Data segmentation – har segment analyse karke insights aur targeted marketing.
  • Classify new data – new sample ko closest cluster centre dein aur us cluster ka manually determined label use karein.
  • Labeled data – cluster samples classification ke liye labeled training data ban jaate hain.
  • Anomaly detection – sab centres se door samples outliers hain, further analysis chahiye (e.g. age 150).

8K-Means Algorithm

Select kinitial centroids
→
Classifyhar sample ko closest centroid assign
→
Recenternew centroid = cluster mean
→
Repeatstopping criterion tak
  • Initial centroids: final clusters in par sensitive hain → different random starts ke saath several runs, best result chuno.
  • Evaluation – WSSE (within-cluster sum of squared error): har sample aur centroid ke squared distance ka all-cluster sum. Numerically lower better, par clustering zyada "correct" hona zaroori nahi; larger k WSSE hamesha ghataata hai.
  • Choosing k: visualization (scatter, dimensionality reduction); application-dependent (product categories/regions ki count); data-driven elbow method: k ke against WSSE plot, bend (e.g. k=3) suggested k deta hai; ambiguous ya try karne ki range mil sakti hai.
  • Stopping: centroid change na ho ya cluster badalne wale samples threshold se kam (e.g. 1%).
  • Interpretation: har centroid cluster ka mean/representative sample; centroid values (e.g. age) compare karke differences dekho.
  • Summary: classic, simple, efficient; k specify karna hota hai; initial centroids ke liye sensitive.

9Parallel K-Means with MapReduce

Ek iteration directly MapReduce mein map hoti hai: Classify = Map (data points par data-parallel), Recenter = Reduce (centers par data-parallel).

PhaseOperation
MapCenters μ1..k aur point xi diye hon: zi = argminj ‖μj − xi‖2; (zi, xi) emit – key=centroid ID, value=data point.
ReduceCluster j ke points lo; μj = (1/nj) Σi: zi=j xi; (j, μj) emit – pehle sum/count, phir sum/count.
reduce(j, x_in_cluster: [x1, x3, ...])
    sum = 0
    count = 0
    for x in x_in_cluster:
        sum += x
        count += 1
    emit(j, sum/count)

Iterative loop: new centers next pass ke liye old version replace karte hain, stopping tak; data points HDFS mein stored hote hain. Practical issues: K-means ko iterative MapReduce chahiye (standard formulation nahi → Spark suitable); mapper ko data point aur all centers chahiye (bahut data), isliye better implementation har mapper ko many points deti hai.

10Quick Revision

Must remember
  • ML = explicit programming ke bina data se learning; supervised (classification, regression) vs unsupervised (clustering, association).
  • Process: Acquire → Prepare (explore, pre-process) → Analyze → Report → Act; iterative.
  • Overfit = low training, high test error; underfit = dono high; pre/post-pruning aur validation se control.
  • Holdout, repeated holdout, k-fold CV, LOOCV (k=N); test set training ke dauran untouched.
  • Accuracy = (TP+TN)/all; precision = TP/(TP+FP); recall = TP/(TP+FN); F1 = 2PR/(P+R).
  • K-means: select centroids → classify → recenter; WSSE, elbow; initial centroids ke liye sensitive.
  • MapReduce K-means: Map = classify (centroid ID, point emit); Reduce = per-centroid average; iterative (Spark).
