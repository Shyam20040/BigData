1Machine Learning Basics

Definition

Machine Learning computer systems ka aisa study hai jahan systems data se learn karte hain without being explicitly programmed.

Models kisi task ko bahut saare examples ko analyse karke learn karte hain.

Example:

Cat ko recognize karne ke liye step-by-step rules program karne ke bajay, model ko bahut saari cat images dikha kar learn karaya ja sakta hai.

Model kitna achha learn karega, ye data ki quantity aur quality par strongly depend karta hai.

ML:

  • Hidden patterns discover karta hai.
  • Trends identify karta hai.
  • Data-driven decisions enable karta hai.

ML ek interdisciplinary field hai jisme:

  • Mathematics & Statistics
  • Computer Science & AI
  • Domain knowledge

include hote hain.

Domain knowledge ka matlab application ko, uske data ko aur outcomes ko kaise use kiya jaayega, ye samajhna hai. Ye successful ML ke liye essential hai.

Examples: Credit-card fraud detection: Purchase ko user ki previous history ke saath compare kiya jaata hai.

Agar purchase bahut different ho, jaise:

  • Big-ticket item
  • Foreign location

to usse fraud ke liye flag kiya ja sakta hai.

Handwritten digit recognition: ATMs cheque amounts read kar sakte hain.

Challenge ye hai ki handwriting person-to-person bahut vary karti hai.

Recommendations: "Customers who bought this also bought…"

Others

  • Targeted mobile ads
  • Sentiment analysis
  • Climate monitoring
  • Crime-pattern detection
  • Drug-effectiveness analysis

Related terms

Data Mining: Databases ya data warehouses mein patterns find karna.

ML ke same algorithms use ho sakte hain, lekin data-access aspects bhi include hote hain.

Predictive Analytics: Data ko analyse karke future outcomes predict karna.

Examples:

  • Sales forecasting
  • Customer behavior

Data Science: Data se meaning extract karna, usually big data se.

Ismein:

  • Data collection
  • Data storage
  • Data management

include hote hain aur ML techniques use ki jaati hain.

Categories of techniques

TechniqueTypeGoal & Examples
ClassificationSupervised, predictiveKisi category ko predict karna: weather (sunny/rainy/windy/cloudy), tumor benign/malignant, rain tomorrow, loan risk high/medium/low, tweet sentiment.
RegressionSupervised, predictiveNumeric value predict karna: stock price (lekin "will it rise or fall" classification hai), product demand, test score, rainfall amount, drug effectiveness.
Cluster analysisUnsupervised, descriptiveSimilar items ko groups mein organize karna: customer segmentation (seniors/adults/teens), topography types, tissue types, weather patterns, crime hot spots.
Association analysisUnsupervised, descriptiveSaath mein occur hone wale items/events ke rules find karna: market-basket analysis, cross-selling CDs → money-market accounts, pages accessed together.

Supervised vs Unsupervised: Supervised = target provided hota hai (labeled data).

Unsupervised = target unknown hota hai (unlabeled data).

3Generalization & Overfitting

Error Rate: Error rate (misclassification rate):

incorrect predictions ÷ total samples

Model:

  • Training data par build hota hai.
  • Separate test data par evaluate hota hai.

Test data training ke time unseen hota hai.

Training Error: Training data par error.

Test Error: Test data par error.

Test error ko generalization error bhi kehte hain.

Ye batata hai ki model new/unseen data ko kitna achha handle karta hai.

Underfitting vs Good Fit vs Overfitting

ConditionTraining ErrorTest ErrorCause
UnderfittingHighHighModel ne data ka structure properly learn nahi kiya.
Good fitLowLowModel underlying trend learn karta hai.
OverfittingVery lowHighModel noise ko model kar raha hai; model too complex hai, yani samples ke comparison mein too many parameters.

Overfit Models: Overfit models generalize nahi karte.

Goal:

Model ko as simple as possible rakho while still solving the mapping.

Overfitting in decision trees

Decision tree repeatedly data ko split karta hai.

Example:

Outlook
Sunny / Overcast / Rain
Humidity, Wind
Yes / No

Agar tree ko unchecked chhod diya jaaye:

  • Ye grow karta rahega.
  • Training data ko perfectly classify kar sakta hai.
  • Noise ke basis par space partition kar sakta hai.

Isliye complexity control karni padti hai.

Methods

MethodHow
Pre-pruningGrowth ko early stop karo restrictive conditions ke saath, e.g. node mein too few samples ya impurity improvement threshold se below. Lekin prematurely stop ho sakta hai.
Post-pruningFull tree grow karo, phir bottom-up prune karo. Agar generalization error improve ya unchanged ho, subtree ko leaf se replace karo. Usually better because full tree use hota hai, but computationally more expensive hai.

4Validation & Model Selection

Validation set training data se carve kiya gaya ek separate set hota hai jo batata hai ki training/model complexity ko kab stop karna hai.

Model complexity ke against error plot karo.

Example:

Number of nodes vs error

  • Training error continuously decrease karta hai.
  • Validation error pehle decrease karta hai.
  • Phir increase hone lagta hai.

Validation error ka rise overfitting indicate karta hai.

Isliye training ko us point par stop karo jahan:

Validation error minimum ho.

Different complexity wale models mein se model choose karna:

Model selection

kehlata hai.

Ye kisi bhi model type par apply hota hai.

Validation error generalization performance ko estimate bhi karta hai.

Validation Methods

MethodDescription & Notes
HoldoutTraining data ka ek part validation set ke liye reserve karo. Limitations: training ke liye less data; agar distributions different hain to misleading result aa sakta hai.
Repeated holdout (random subsampling)Har baar different random holdout set use karke repeat karo; validation errors ka average lo.
K-fold cross-validationData ko k disjoint partitions mein split karo. Har iteration mein ek partition validation ke liye use hota hai; total k times. Har partition exactly once use hota hai. Errors ka average lo aur smallest average wala model choose karo. Very common; single split ki variability reduce karta hai.
Leave-one-out (LOOCV)k-fold jahan k = N; validation set mein one sample hota hai aur training N−1 samples par hoti hai.
Three datasets

Model parameters fit karne ke liye.

Validation: Training ko kab stop karna hai decide karne ke liye aur overfitting avoid karne ke liye.

Test: New data par final evaluation ke liye.

Important: Test set ko model build ya tune karne ke liye kabhi use nahi karna chahiye.

Cross-validation mein bhi test set use nahi hota.

Test set end tak untouched rehna chahiye.

All datasets mein same class distribution hona chahiye.

Example:

Agar original distribution 70% / 30% hai, to ye proportion datasets mein preserve hona chahiye.

Otherwise results misleading ho sakte hain.

5Evaluation Metrics

Binary/yes-no classification ke liye:

Example:

"Is this animal a mammal?"

Confusion Matrix

True LabelPredicted: YesPredicted: No
YesTrue Positive (TP)False Negative (FN)
NoFalse Positive (FP)True Negative (TN)

Metrics

MetricFormulaMeaning
Accuracy(TP+TN) / (TP+TN+FP+FN)Correct predictions ÷ total
Error rate1 − AccuracyIncorrect ÷ total
PrecisionTP / (TP+FP)Predicted Yes samples mein se kitne actually Yes hain — exactness
RecallTP / (TP+FN)Actual Yes samples mein se kitne find kiye gaye — completeness
F-measureF1 = 2·P·R / (P+R)Precision aur recall ko combine karta hai; F1 equally weight karta hai, F2 recall ko more weight karta hai, F0.5 precision ko more weight karta hai.

Example: Given:

  • TP = 3
  • FN = 2
  • FP = 1
  • TN = 4

Accuracy: accuracy = 7/10 = 0.7

Error Rate: error rate = 1 − 0.7 = 0.3

Precision: precision = 3/4 = 0.75

Recall: recall = 3/5 = 0.6

7Cluster Analysis

Goal: Similar items ko groups, yani clusters, mein organize karna taaki har cluster ko closely analyse kiya ja sake.

Objective:

  • Intra-cluster differences minimize karna.
  • Inter-cluster differences maximize karna.

Yaani:

Same cluster ke samples close hone chahiye.

Different clusters ke samples far hone chahiye.

Ye kisi similarity measure ke basis par hota hai.

Applications

  • Customer segmentation by purchase history
    • Sci-fi
    • Non-fiction
    • Children's books
  • Weather patterns
  • News ko topics mein group karna
  • Crime hot spots

Similarity / Distance Measures

Similarity MeasureDescription
Euclidean distancePoints A aur B ke beech straight-line distance.
Manhattan distanceSirf axes ke along path; horizontal + vertical steps.
Cosine similarityVectors ke beech angle ka cosine. cos θ = xi·xq / (‖xi‖‖xq‖); inner product = Σ xi[j]·xq[j].

Cosine Similarity: Formula:

cos θ = xi·xq / (‖xi‖‖xq‖)

Inner product:

Σ xi[j]·xq[j]

Values

  • θ = 0 → similarity 1
  • θ = 90° → similarity 0
  • Range → −1 to 1

Positive features, jaise tf-idf, ke case mein:

0 to 1

Distance:

1 − similarity

Cosine similarity ek proper distance metric nahi hai, lekin sparse vectors ke liye efficient hai.

Normalization: Vector ko uske norm se divide kiya jaata hai.

Example:

norm = √(1+25+9+1) = 6

Distance measures mein inputs ko normalize karna pad sakta hai, otherwise koi ek variable disproportionately dominate kar sakta hai.

Key points
  • Clustering unsupervised hai.
  • Ismein target nahi hota.
  • Koi single "correct" clustering nahi hoti.
  • Clustering application/use-case par depend karti hai.
  • Clusters ke labels automatically nahi milte.
  • Interpretation aur analysis required hota hai.

Uses of cluster results

Data Segmentation: Har segment ko separately analyse karke:

  • Insights
  • Targeted marketing

kiya ja sakta hai.

Classify New Data: New sample ko closest cluster centre assign karo.

Phir us cluster ka manually determined label use kiya ja sakta hai.

Labeled Data: Cluster samples ko labeled training data ki tarah use karke classification ki ja sakti hai.

Anomaly Detection: Jo samples har centre se far hain, wo outliers ho sakte hain.

8K-Means Algorithm

K-Means iterative algorithm hai.

Process:

Select k: Initial centroids select karo.

↓

Classify: Har sample ko closest centroid assign karo.

↓

Recenter: Har cluster ka new centroid:

cluster ka mean

hota hai.

↓

Repeat: Stopping criterion satisfy hone tak repeat karo.

Initial Centroids: Final clusters initial centroids ke liye sensitive hote hain.

Isliye:

  • Algorithm ko several times run karo.
  • Different random starting centroids use karo.
  • Best result choose karo.

Evaluation — WSSE: WSSE = Within-Cluster Sum of Squared Error

Har cluster mein:

sample aur centroid ke beech squared distance

calculate karke sabhi clusters ke across sum kiya jaata hai.

Lower WSSE numerically better hota hai.

Lekin:

Lower WSSE ka matlab necessarily more "correct" clustering nahi hota.

Important:

Larger k always WSSE reduce karta hai.

Choosing k: Visualization

  • Scatter plots
  • Dimensionality reduction

Application-dependent: Example:

  • Number of product categories
  • Number of regions

Data-driven — Elbow Method: WSSE ko k ke against plot karo.

Jahan graph mein noticeable bend/elbow aaye, wo suitable k suggest kar sakta hai.

Example:

k = 3

Lekin elbow:

  • Ambiguous ho sakta hai.
  • Ek range of k try karne ko suggest kar sakta hai.

Stopping Criteria: K-Means stop ho sakta hai jab:

  • Centroids mein koi change na ho.
  • Cluster change karne wale samples threshold se below ho jaayein.

Example:

< 1% samples changing clusters

Interpretation: Har centroid:

us cluster ke samples ka mean

hota hai.

Isliye centroid ek representative sample ki tarah interpret kiya ja sakta hai.

Centroid values compare karke clusters ka difference samajh sakte hain.

Example:

Age values compare karna.

K-Means Summary

  • Classic
  • Simple
  • Efficient
  • k pehle specify karna padta hai.
  • Initial centroids ke liye sensitive hai.

9Parallel K-Means with MapReduce

K-Means ka one iteration directly MapReduce mein map kiya ja sakta hai.

Classify: Map

Data points ke across data-parallel operation.

Recenter: Reduce

Centers ke across data-parallel operation.

Map Phase: Given:

  • Centers μ1..k
  • Point xi

Closest centroid find karo:

zi = argminj ‖μj − xi‖²

Emit:

(zi, xi)

where:

  • Key = centroid ID
  • Value = data point

Reduce Phase: Cluster j ke saare assigned points receive karo.

New centroid:

μj = (1/nj) Σi: zi=j xi

Yaani:

  1. Sum calculate karo.
  2. Count calculate karo.
  3. sum/count karo.

Reduce Pseudocode

reduce(j, x_in_cluster: [x1, x3, ...])
    sum = 0
    count = 0
    for x in x_in_cluster:
        sum += x
        count += 1
    emit(j, sum/count)

Iterative Loop: New centers:

old centers ko replace karte hain

aur next pass mein use hote hain.

Ye process stopping condition tak repeat hota hai.

Data points:

HDFS

mein stored hote hain.

Practical Issues: K-Means ko iterative MapReduce chahiye.

Ye standard MapReduce formulation nahi hai.

Isi wajah se:

Spark K-Means ke liye well suited hai.

Ek mapper ko:

  • Data point
  • All centers

dono chahiye.

Agar centers bahut data represent karte hain, to ye costly ho sakta hai.

Better implementation mein:

Har mapper ko many data points assign kiye jaate hain.

10Quick Revision

Must Remember

Must Remember: Machine Learning: ML = data se learning without explicit programming

Supervised

  • Classification
  • Regression

Unsupervised

  • Clustering
  • Association

ML Process: Acquire → Prepare → Analyze → Report → Act

Process:

Iterative

Overfitting: Overfitting = low training error + high test error

Underfitting = high training error + high test error

Overfitting control:

  • Pre-pruning
  • Post-pruning
  • Validation

Validation: Methods:

  • Holdout
  • Repeated holdout
  • K-fold cross-validation
  • LOOCV (k = N)

Test set is never touched during training/model tuning.

Evaluation Metrics: Accuracy: Accuracy = (TP+TN)/all

Precision: Precision = TP/(TP+FP)

Recall: Recall = TP/(TP+FN)

F1: F1 = 2PR/(P+R)

K-Means: Process:

Select centroids → Classify → Recenter

Important:

  • WSSE
  • Elbow method
  • Initial centroids sensitivity
  • k must be specified

MapReduce K-Means: Map: Classify

→ emit:

(centroid id, point)

Reduce: Average points per centroid

K-Means requires iteration, which is one reason Spark is well suited for it.
