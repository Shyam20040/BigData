1Decision Trees

A decision tree is an acyclic graph of decision nodes: a root, internal nodes (each tests an attribute) and leaves (predictions). Divide and conquer: split data into subsets, check whether each subset is pure (all yes or all no); if pure stop, otherwise repeat; a new sample is predicted by the subset it falls into.

Example: will Sachin play cricket? (14 days: 9 Yes / 5 No)

Outlook9 yes / 5 no
→
Overcast4/0 pure → Yes
Sunny2/3 → split on Humidity: High 0/3 → No; Normal 2/0 → Yes
Rain3/2 → split on Wind: Weak 3/0 → Yes; Strong 0/2 → No

New day D15 (Rain, High humidity, Weak wind) → Rain → Wind = Weak → Yes (3/0).

Single decision tree – summary+ Handles feature interactions automatically (complex functions with multiple splits); + computationally scalable (efficient algorithms for very large data with many features, e.g. on Spark clusters); + interpretable (visualize splits and leaves); − weak predictive power (overfitting/noise).

2ID3, Entropy & Information Gain

ID3 (Iterative Dichotomiser 3, Ross Quinlan 1986) generates a decision tree from a dataset; precursor of C4.5 (1993); CART (Breiman et al., 1984) comes from statistics.

Split(node, {examples}):
 1. A ← best attribute for splitting {examples}
 2. Decision attribute for this node ← A
 3. For each value of A, create a new child node
 4. Split training {examples} to child nodes
 5. For each child subset: if pure → STOP, else Split(child, subset)

Which attribute? Measure the "purity" of a split. A pure set (4 yes/0 no) is completely certain; 3 yes/3 no is completely uncertain (50%). The measure must be symmetric (4 yes/0 no as pure as 0 yes/4 no), so P("yes"|set) can't be used → use entropy.

Entropy (bits)H(S) = −p(+) log₂ p(+) − p(−) log₂ p(−). Interpretation: bits needed to tell whether an item X of S is positive or negative. Maximum 1 at p(+) = ½; 0 when pure (p = 0 or 1). E.g. 3 yes/3 no → 1; 4 yes/0 no → 0.
Information GainExpected drop in entropy after a split (mutual information between attribute A and class labels): Gain(S,A) = H(S) − Σv∈Values(A) (|Sv|/|S|) · H(Sv). The tree grows greedily top-down, each split maximizing IG.

Worked example, Gain(S, Wind): H(S) = 0.94 (9 yes/5 no); H(Sweak) = 0.81 (6/2); H(Sstrong) = 1.0 (3/3). Gain = 0.94 − 8/14·0.81 − 6/14·1.0 = 0.049.

3Decision Trees for Regression

Given training set Z = {(x1,y1),…} with real targets yi, find f(x) minimizing Σ(f(xi) − yi)². A node splits by condition xk < t into ZL (yes, prediction aL) and ZR (no, prediction aR).

  • No split: predict one number â minimizing squared error; it equals the average of all targets: â = (1/|Z|) Σ yi. Impurity(Z) = mean squared error = (1/|Z|) Σ(â − yi)².
  • Best split: choose k, t (and leaf values, which are the means âL, âR of each side) by maximizing IG = Impurity(Z) − (|ZL|/|Z|·Impurity(ZL) + |ZR|/|Z|·Impurity(ZR)) (error before split minus error after). Repeated from top to bottom.
Stopping rules(1) node depth equals maxDepth; (2) no split gives information gain above minInfoGain; (3) no split gives children with at least minInstancesPerNode training instances each.

4Building Trees with MapReduce: PLANET

Problem: huge dataset with hundreds of attributes – the tree is small (shallow, ~10 levels, fits in memory) but the data is too large for one machine. PLANET (Parallel Learner for Assembling Numerous Ensemble Trees, Panda et al., VLDB '09) is a sequence of MapReduce jobs; setting: numerical attributes, numerical target (regression), binary splits Xj < v.

Mapperloads model; "drops" each data point to its leaf; keeps partial statistics for each candidate split
→
Reduceraggregates statistics, picks best split per node
→
Mastergrows the tree one level per MapReduce step
PLANET jobPurpose
Initialization (once, first)Identify the attribute values to consider for splits.
FindBestSplit (many times)Find best splits when data is too large for memory.
InMemoryBuild (once, last)When a node's data fits in memory, grow an entire sub-tree.

The Master monitors everything and runs the jobs.

5Bootstrap & Bagging

BootstrapProduces replicas of dataset Z by random sampling with replacement; each pick is independent. The new dataset has the same size n, but some objects are missing and others repeat (e.g. original 1 2 3 4 5 → bootstrap 3 1 5 5 2).
Bagging (Bootstrap Aggregation)A general method for averaging predictions of any algorithm (not only trees); reduces the variance of the prediction.
Input: training set Z, B iterations, learning method M
For b = 1..B: draw bootstrap sample Z*b of size n; apply M → model f*b(x)
Return ensemble {f*1 … f*B}
Regression:     f(x) = (1/B) Σ f*b(x)
Classification: majority vote of the B predictions

Why it works: the training set is itself random (user behavior, noisy physical measurements). Averaging over possible datasets removes the noisy, unstable parts of models while stable, reliable parts remain – based on the bias-variance trade-off. Bagging improves almost any method but is very time-consuming for large data.

6Random Forest

DefinitionRandom Forest = bagging of de-correlated decision trees. For b = 1..B: draw a bootstrap sample, grow a de-correlated tree Tb; return ensemble. Regression: average; classification: majority vote.
  • De-correlation: the tree is grown greedily top-down, but at each split only m randomly selected input variables (m ≤ p) are candidates; each split maximizes information gain. Recommended (inventors): m = √p for classification, m = p/3 for regression; minInstancesPerNode = 5 for regression.
  • Experiment: m = √p (de-correlated trees) is worse for the first ~20 trees but eventually converges to a better result than a single DT or trees using all variables.
PropertySingle treeRandom ForestGradient Boosted Trees
Predictive powerPoorBetter than a tree, slightly worse than GBDTBest general-purpose
InterpretabilityGoodLost (hundreds/thousands of trees)Poor
Parallelism–Trees are independent → essentially parallel, trainable in distributed settingSequential iterations

Order of quality: Single DT < Random Forest < Gradient Boosted DT; there is always a trade-off between predictive power and interpretability.

7Gradient Boosted Decision Trees

Boosting combines outputs of many weak (base) classifiers into a powerful ensemble; variants: AdaBoost, BrownBoost, LogitBoost, Gradient Boosting. For big data with many examples/features there are two ways to get a complex model: start complex and fit parameters (neural network), or build iteratively, training a simple model at each step (boosting).

Regression: f(x) = Σ h_m(x), each h_m a decision tree
f0(x) = (1/n) Σ y_i                      # initial mean label
For m = 1..M:
   ŷ_i = y_i − f_{m−1}(x_i)              # residuals
   fit tree h_m to targets ŷ_i (auxiliary training set)
   f_m(x) = f_{m−1}(x) + v · h_m(x)
Return f_M ;  v = regularization (learningRate), recommended ≤ 0.1
Link to optimizationGradient boosting is like gradient descent: move opposite to the gradient with a small step size (here v). It is a minimization in the functional space.

Classification: labels y ∈ {0,1}; probabilistic model P(y=1|x) = 1 / (1 + exp(−f(x))), 0 < P < 1; maximize the log-likelihood Q[f] = Σ log P(yi|xi) (equivalently minimize loss L(yi, f(xi))); each tree is fitted to gradients gi = dL/df. Summary: GBDT is considered the best general-purpose algorithm for classification/regression.

9Cross-Validation in Spark ML

Cross-validation assesses model quality and finds the best model within a family. Build a Pipeline (here a single stage: the decision tree; in general also preprocessing, string indexing…), a ParamGridBuilder (e.g. maxDepth in [1,2,4,5,6,7,8]; optionally also minInstancesPerNode – more parameters make training slower), an evaluator (accuracy) and a CrossValidator with numFolds = 10 (folds should not be fewer than 5 or 10).

crossval = CrossValidator(estimator=pipeline, estimatorParamMaps=paramGrid,
                          evaluator=evaluator, numFolds=10)
cvModel = crossval.fit(inputDF2)      # trains/evaluates 10 times per setting
cvModel.avgMetrics                    # mean accuracy per maxDepth
cvModel.bestModel.stages[0]

Average accuracies for the seven depths: 0.892, 0.920, 0.942, 0.942, 0.946, 0.938, 0.936. The best model has depth 6 and 47 nodes and can then predict on any other dataset.

10Quick Revision

Must remember
  • Entropy H = −Σ p log₂ p (0 pure, 1 for 50:50); Gain = H(S) − weighted child entropies; ID3 splits greedily on max gain; Gain(S, Wind) = 0.049.
  • Regression tree: leaf = mean; impurity = MSE; stop by maxDepth, minInfoGain, minInstancesPerNode.
  • PLANET: one MapReduce step per tree level; Initialization → FindBestSplit (repeated) → InMemoryBuild.
  • Bootstrap = sampling with replacement; bagging = average/majority vote, reduces variance.
  • Random forest = bagging + random m of p features per split (√p classification, p/3 regression); trees independent → parallel.
  • GBDT: f0 = mean, fit residuals, f_m = f_{m−1} + v·h_m (v ≤ 0.1); gradient descent in functional space.
  • Single DT < Random Forest < GBDT in accuracy; the reverse in interpretability.
  • Spark ML: StringIndexer, 70/30 split, DecisionTree/GBT/RandomForest classifiers; CrossValidator with ParamGrid, 10 folds → best depth 6.
