2Distributed Computing

Centralized vs distributed

Early computing ek single processor par hota tha; uni-processor computing centralized computing kehlata hai (mainframe se connected terminals). Distributed computing me multiple computers (workstations, hosts) ek network link se connected hote hain.

DefinitionDistributed computing ek aisi computing science hai jo distributed systems ko study karti hai aur unka use computational problems solve karne ke liye karti hai.
Distributed system me multiple autonomous computational entities hote hain, har ek ke paas apni local memory hoti hai, aur woh message passing ke through communicate karte hain.

Examples: Internet, ATM machines, intranets/workgroups. Aane wale samay me computing landscape me ubiquitous network-connected devices dominate karenge.

3Grid Computing

Grid computing ek aisi architecture hai jahan distributed resources ko loosely coupled manner me combine karke ek large-scale task solve kiya jata hai. Resources geographically dispersed aur multiple administrative domains me ho sakte hain.

Key ideaGrid ka main objective heterogeneous resources ko ek single virtual platform ke roop me present karna hai, jahan users ko task execute karne ke liye high-level abstraction milta hai.

4Cluster Computing

Cluster computing me multiple computers (nodes) ko close proximity me connect karke ek single unit ke roop me use kiya jata hai. Yeh high availability, load balancing, aur parallel processing ke liye popular hai.

DifferenceGrid usually geographically distributed aur heterogeneous hota hai, jabki cluster aam taur par local network me connected, homogeneous ya nearly homogeneous nodes hota hai.

5Utility Computing

Utility computing me computing resources ko utility jaise electricity/water ki tarah treat kiya jata hai — users ko required amount of resources pay-per-use ke basis par milte hain.

Main ideaResources ko dynamically provision kiya jata hai aur user ko consumption ke hisaab se payment hoti hai, jisse scalability aur cost efficiency improve hoti hai.

6Cloud Computing (NIST Model)

Cloud computing ko NIST ne define kiya hai jaise:

DefinitionCloud computing ek model hai jisme convenient, on-demand network access provide kiya jata hai, shared pool of configurable computing resources (network, servers, storage, applications, services) ko rapid provisioning aur minimal management effort ke saath provide karna.

Five essential characteristics

  • On-demand self-service: User ko manually permission lene ki need nahi hoti.
  • Broad network access: Services network ke through accessible hote hain.
  • Resource pooling: Multiple customers ko shared infrastructure se resources dynamically allocate kiye jate hain.
  • Rapid elasticity: Resources demand ke hisaab se fast scale up/down ho sakte hain.
  • Measured service: Resource usage monitor aur charge ke liye measure kiya jata hai.

8Deployment Models aur Virtualization

Cloud deployment models me Public, Private, Community, aur Hybrid shamil hote hain.

  • Public cloud: Services general public ke liye available hote hain.
  • Private cloud: Sirf ek organization ke liye dedicated hota hai.
  • Community cloud: Same community/industry ke organizations ke liye shared.
  • Hybrid cloud: Public + private combinations for flexibility.

Virtualization: Multiple VMs ek same physical machine par run ho sakte hain. Yeh host hardware resources ko share karke multiple isolated guest OS provide karta hai.

9Advantages aur Limitations

Cloud computing ke advantages me scalability, cost reduction, pay-per-use, rapid availability, resource pooling, high availability, aur easy maintenance shamil hain.

Limitations me security concerns, network dependency, vendor lock-in, migration challenges, aur performance variation include ho sakte hain.

10Economics of Cloud

Cloud models cost aur usage ko measure karne ki capability dete hain, jisse resource consumption ko optimize karna easy hota hai. Large-scale shared infrastructure se fixed costs kam hoti hain.

TakeawayCloud economics ka core idea hai ki users sirf use kiya hua capacity pay karte hain, instead of upfront heavy hardware investment.

11Cloud Architecture

Cloud architecture me frontend, middleware, backend, networking, storage, aur virtualization layers shamil hote hain. Service delivery typically multi-tenant, virtualized and internet-based hoti hai.

12Cloud Networking

Cloud networking me virtual machines, virtual networks, routers, firewalls, load balancers, aur security rules ka role hota hai. Layered abstraction se provider ko higher-level service management easy hota hai.

13Quick Revision

  • Distributed computing, grid, cluster, utility aur cloud ek evolution chain hai.
  • Cloud computing ke NIST characteristics: on-demand, broad access, pooling, elasticity, measured service.
  • SaaS, PaaS, aur IaaS service abstraction ke different levels represent karte hain.
  • Virtualization aur resource pooling cloud core concepts hain.
  • Public, private, community, aur hybrid deployment models different organizational needs ko satisfy karte hain.
