Cloud Computing – Week 1 Practice Set

20 MCQs with answers and explanation-ready key

1Questions 1–10

Q1. Which of the following best represents the meaning of resource pooling in cloud computing?

  1. A. Every customer receives a permanently dedicated physical server.
  2. B. Computing resources are dynamically assigned to multiple customers using a shared infrastructure.
  3. C. Resources can only be accessed from a local network.
  4. D. Users must manually allocate hardware before using cloud services.
Final Answer: B

Q2. A startup rents virtual servers on Amazon EC2. The team installs and patches its own operating system, configures the web server, and manages the runtime and applications itself. The provider supplies only the virtualized compute, storage, and networking. This is best classified as:

  1. A. SaaS
  2. B. PaaS
  3. C. IaaS
  4. D. FaaS
Final Answer: C

Q3. Which deployment model allows an organization to maintain cloud infrastructure exclusively for its own use, either on-premises or hosted by a third party?

  1. A. Public Cloud
  2. B. Hybrid Cloud
  3. C. Community Cloud
  4. D. Private Cloud
Final Answer: D

Q4. Virtualization technology allows multiple virtual machines (VMs) to run on a single physical system or on a cluster of physical systems. Which of the following statements is the MOST accurate?

  1. A. Each VM always shares the same operating system kernel with the host OS.
  2. B. Multiple VMs can run different operating systems on the same physical machine simultaneously.
  3. C. Virtualization is only possible in cloud computing environments.
  4. D. Virtualization prevents resource overcommitment on the host system.
Final Answer: B

Q5. Consider the following statements about distributed systems (DS):

(i) DS can improve scalability by adding more nodes to the system.
(ii) DS can increase fault tolerance through data and service replication.
(iii) DS guarantees lower latency for every single operation compared to a centralized system.

  1. A. (i) and (ii)
  2. B. Only (iii)
  3. C. (i) and (iii)
  4. D. (i), (ii), and (iii)
Final Answer: A

Q6. The combination of Service-Oriented Architecture (SOA) and Cloud Computing led to a paradigm where almost any IT capability can be delivered as a network-accessible service. This is often referred to as:

  1. A. FTP
  2. B. SNTP
  3. C. XaaS
  4. D. FaaS
Final Answer: C

Q7. Which of the following correctly describes a Type-2 (hosted) hypervisor?

  1. A. It runs directly on the physical hardware without any underlying operating system.
  2. B. It runs as an application on top of a host operating system.
  3. C. It always provides lower virtualization overhead than a Type-1 hypervisor.
  4. D. It cannot run more than one virtual machine at a time.
Final Answer: B

Q8. Which of the following are advantages of Platform-as-a-Service (PaaS)?

(i) Developers can focus primarily on application development.
(ii) Automatic software updates for the underlying platform.
(iii) Complete control over physical server hardware.
(iv) Faster application deployment.

  1. A. (i), (ii), and (iv)
  2. B. (ii) and (iii)
  3. C. (i) and (iii)
  4. D. (i), (ii), (iii), and (iv)
Final Answer: A

Q9. Which of the following services is most likely to be classified as Infrastructure as a Service (IaaS)?

  1. A. Microsoft Word Online
  2. B. Amazon EC2 Virtual Machines
  3. C. Google Docs
  4. D. Salesforce CRM
Final Answer: B

Q10. A __________ is a form of distributed computing in which a large number of geographically dispersed and often heterogeneous resources across multiple administrative domains are loosely coupled and coordinated to work together on a common, large-scale task.

  1. A. Cluster
  2. B. Grid
  3. C. Node
  4. D. Hypervisor
Final Answer: B

2Questions 11–20

Q11. Which of the following is NOT one of the five essential characteristics of cloud computing defined by NIST?

  1. A. On-demand self-service
  2. B. Broad network access
  3. C. Resource pooling
  4. D. Dedicated physical hardware for every customer
Final Answer: D

Q12. Which of the following correctly represents the order of computing paradigms discussed in the course?

  1. A. Distributed → Cluster → Grid → Utility → Cloud
  2. B. Distributed → Grid → Cluster → Utility → Cloud
  3. C. Grid → Distributed → Cluster → Cloud → Utility
  4. D. Cluster → Distributed → Grid → Cloud → Utility
Final Answer: B

Q13. Which of the following is the BEST description of rapid elasticity in cloud computing?

  1. A. Resources are permanently allocated to each customer.
  2. B. Resources can be rapidly provisioned and released according to demand.
  3. C. Users must manually purchase physical servers whenever demand increases.
  4. D. Resources can only be increased but never decreased.
Final Answer: B

Q14. A cloud provider serves multiple customers using a common pool of computing resources while dynamically assigning resources according to demand. This concept is known as:

  1. A. Resource pooling
  2. B. Vertical scaling
  3. C. Dedicated hosting
  4. D. Single system image
Final Answer: A

Q15. Which of the following correctly distinguishes vertical scaling from horizontal scaling?

  1. A. Vertical scaling adds more machines, while horizontal scaling increases the capacity of one machine.
  2. B. Vertical scaling increases resources of a single computation unit, while horizontal scaling adds more computation units.
  3. C. Both methods require increasing resources of the same physical machine.
  4. D. Horizontal scaling means replacing software with hardware.
Final Answer: B

Q16. In a three-tier client–server architecture, which tier is responsible for coordinating the application, processing commands, making logical decisions, and performing calculations?

  1. A. Presentation tier
  2. B. Logic tier
  3. C. Data tier
  4. D. Physical tier
Final Answer: B

Q17. Which statement correctly describes the difference between SaaS, PaaS, and IaaS?

  1. A. SaaS provides fundamental infrastructure, PaaS provides physical servers, and IaaS provides only applications.
  2. B. SaaS allows users to use applications, PaaS allows developers to deploy applications, and IaaS provides fundamental computing resources.
  3. C. SaaS and PaaS are identical, while IaaS is only used for networking.
  4. D. IaaS provides applications, while SaaS provides virtual machines.
Final Answer: B

Q18. A company needs additional computing capacity only when its private cloud becomes overloaded and wants to release those resources when the workload decreases. Which concept is most appropriate?

  1. A. Cloud bursting
  2. B. Virtual LAN
  3. C. Single system image
  4. D. Dedicated hosting
Final Answer: A

Q19. Which of the following BEST describes Network Function Virtualization (NFV)?

  1. A. Replacing software-based network functions with dedicated physical appliances.
  2. B. Implementing network functions as software running on standard server hardware.
  3. C. Restricting network functions to one physical location.
  4. D. Providing every network function with a separate physical server.
Final Answer: B

Q20. Which statement about cloud networking and service models is CORRECT?

  1. A. As the level of abstraction increases, the customer generally manages more physical network layers.
  2. B. In SaaS, the customer is responsible for managing the physical and data-link layers.
  3. C. As the cloud service model becomes more abstract, the provider generally handles more layers.
  4. D. IaaS completely removes the customer's responsibility for operating systems and applications.
Final Answer: C
