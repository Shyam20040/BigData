Cloud Computing – Week 1 Practice Set (Hinglish)

20 MCQs, Hinglish explanation-ready answers

1Questions 1–10

Q1. Cloud computing me resource pooling ka matlab kya hota hai?

  1. A. Har customer ko permanent dedicated physical server milta hai.
  2. B. Computing resources ko multiple customers ko shared infrastructure ke through dynamically assign kiya jata hai.
  3. C. Resources sirf local network se access ho sakte hain.
  4. D. Users ko cloud services use karne se pehle hardware ko manually allocate karna padta hai.
Final Answer: B

Q2. Ek startup Amazon EC2 par virtual servers rent karta hai. Team apna operating system install aur patch karta hai, web server configure karta hai aur runtime aur applications khud manage karta hai. Provider sirf virtualized compute, storage aur networking deta hai. Yeh best classified hai:

  1. A. SaaS
  2. B. PaaS
  3. C. IaaS
  4. D. FaaS
Final Answer: C

Q3. Kaun sa deployment model ek organization ko apni cloud infrastructure ko exclusively apne liye maintain karne ki permission deta hai, either on-premises ya third party ke through hosted?

  1. A. Public Cloud
  2. B. Hybrid Cloud
  3. C. Community Cloud
  4. D. Private Cloud
Final Answer: D

Q4. Virtualization technology multiple virtual machines (VMs) ko ek single physical system ya physical systems ke cluster par run karne ki anumati deti hai. Niche diye gaye statements me se sabse sahi statement kaun sa hai?

  1. A. Har VM hamesha host OS ke saath same operating system kernel share karta hai.
  2. B. Multiple VMs same physical machine par ek saath different operating systems run kar sakte hain.
  3. C. Virtualization sirf cloud computing environments me possible hai.
  4. D. Virtualization host system par resource overcommitment ko rokta hai.
Final Answer: B

Q5. Distributed systems (DS) ke baare me statements ko dekhiye:

(i) DS nodes ko add karke scalability improve kar sakta hai.
(ii) DS data aur service replication ke through fault tolerance badha sakta hai.
(iii) DS centralized system ke comparison me har single operation ke liye lower latency guarantee karta hai.

  1. A. (i) aur (ii)
  2. B. Sirf (iii)
  3. C. (i) aur (iii)
  4. D. (i), (ii), aur (iii)
Final Answer: A

Q6. Service-Oriented Architecture (SOA) aur Cloud Computing ka combination ek aisi paradigm banata hai jisme almost any IT capability ko network-accessible service ke roop me deliver kiya ja sakta hai. Isse generally kya refer kiya jata hai?

  1. A. FTP
  2. B. SNTP
  3. C. XaaS
  4. D. FaaS
Final Answer: C

Q7. Type-2 (hosted) hypervisor ko sahi tarah se describe karne wala statement kaun sa hai?

  1. A. Yeh physical hardware par directly run hota hai bina kisi underlying operating system ke.
  2. B. Yeh host operating system ke upar ek application ke roop me run hota hai.
  3. C. Yeh Type-1 hypervisor se hamesha lower virtualization overhead provide karta hai.
  4. D. Yeh ek se jyada virtual machine ko ek saath run nahi kar sakta.
Final Answer: B

Q8. Platform-as-a-Service (PaaS) ke kuch advantages kya hain?

(i) Developers primarily application development par focus kar sakte hain.
(ii) Underlying platform ke liye automatic software updates.
(iii) Physical server hardware par complete control.
(iv) Faster application deployment.

  1. A. (i), (ii), aur (iv)
  2. B. (ii) aur (iii)
  3. C. (i) aur (iii)
  4. D. (i), (ii), (iii), aur (iv)
Final Answer: A

Q9. Niche diye gaye services me se kaunsa Infrastructure as a Service (IaaS) ke roop me classify hone ke liye sabse zyada probable hai?

  1. A. Microsoft Word Online
  2. B. Amazon EC2 Virtual Machines
  3. C. Google Docs
  4. D. Salesforce CRM
Final Answer: B

Q10. A __________ ek distributed computing ka form hai, jisme geographically dispersed aur aksar heterogeneous resources multiple administrative domains me loosely coupled aur coordinated hote hain aur common, large-scale task par kaam karte hain.

  1. A. Cluster
  2. B. Grid
  3. C. Node
  4. D. Hypervisor
Final Answer: B

2Questions 11–20

Q11. NIST ke definition ke according cloud computing ke five essential characteristics me se kaun sa ek NOT included hai?

  1. A. On-demand self-service
  2. B. Broad network access
  3. C. Resource pooling
  4. D. Har customer ke liye dedicated physical hardware
Final Answer: D

Q12. Course me discuss kiye gaye computing paradigms ka correct order kaun sa hai?

  1. A. Distributed → Cluster → Grid → Utility → Cloud
  2. B. Distributed → Grid → Cluster → Utility → Cloud
  3. C. Grid → Distributed → Cluster → Cloud → Utility
  4. D. Cluster → Distributed → Grid → Cloud → Utility
Final Answer: B

Q13. Cloud computing me rapid elasticity ka sabse sahi description kya hai?

  1. A. Resources har customer ko permanently allocate kiye jaate hain.
  2. B. Resources demand ke according rapidly provision aur release kiye ja sakte hain.
  3. C. Users ko demand badhne par manually physical servers purchase karne padte hain.
  4. D. Resources sirf increase ho sakte hain, decrease nahi ho sakte.
Final Answer: B

Q14. Ek cloud provider multiple customers ko common pool of computing resources provide karta hai aur demand ke according dynamically resources assign karta hai. Is concept ko kya kehte hain?

  1. A. Resource pooling
  2. B. Vertical scaling
  3. C. Dedicated hosting
  4. D. Single system image
Final Answer: A

Q15. Vertical scaling aur horizontal scaling me se kaunsa statement sahi tarah distinguish karta hai?

  1. A. Vertical scaling more machines add karta hai, horizontal scaling ek machine ki capacity increase karta hai.
  2. B. Vertical scaling ek single computation unit ke resources ko increase karta hai, while horizontal scaling more computation units add karta hai.
  3. C. Dono methods same physical machine ke resources increase karne ki require karte hain.
  4. D. Horizontal scaling ka matlab software ko hardware se replace karna hai.
Final Answer: B

Q16. Three-tier client–server architecture me kaun sa tier application ko coordinate karta hai, commands process karta hai, logical decisions leta hai aur calculations perform karta hai?

  1. A. Presentation tier
  2. B. Logic tier
  3. C. Data tier
  4. D. Physical tier
Final Answer: B

Q17. SaaS, PaaS, aur IaaS ke beech difference ko sahi tarah se describe karne wala statement kaun sa hai?

  1. A. SaaS fundamental infrastructure provide karta hai, PaaS physical servers provide karta hai, aur IaaS sirf applications provide karta hai.
  2. B. SaaS users ko applications use karne ki permission deta hai, PaaS developers ko applications deploy karne deta hai, aur IaaS fundamental computing resources provide karta hai.
  3. C. SaaS aur PaaS identical hain, while IaaS sirf networking ke liye use hota hai.
  4. D. IaaS applications provide karta hai, while SaaS virtual machines provide karta hai.
Final Answer: B

Q18. Ek company ko additional computing capacity tab chahiye jab uska private cloud overloaded ho aur jab workload kam ho to un resources ko release karna chahata hai. Kaun sa concept sabse appropriate hai?

  1. A. Cloud bursting
  2. B. Virtual LAN
  3. C. Single system image
  4. D. Dedicated hosting
Final Answer: A

Q19. Network Function Virtualization (NFV) ko sabse acche se describe karne wala statement kaun sa hai?

  1. A. Software-based network functions ko dedicated physical appliances se replace karna.
  2. B. Network functions ko standard server hardware par software ke roop me implement karna.
  3. C. Network functions ko ek physical location tak restrict karna.
  4. D. Har network function ko alag physical server provide karna.
Final Answer: B

Q20. Cloud networking aur service models ke baare me sahi statement kaun sa hai?

  1. A. Jab abstraction level increase hota hai, customer generally zyada physical network layers manage karta hai.
  2. B. SaaS me customer ko physical aur data-link layers manage karne ki responsibility hoti hai.
  3. C. Jab cloud service model zyada abstract hota hai, provider generally zyada layers handle karta hai.
  4. D. IaaS customer ki operating systems aur applications ke liye responsibility ko completely remove kar deta hai.
Final Answer: C
